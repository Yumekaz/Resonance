Set up listening on your computer and phone
  1. Choose your music folder. Open it in your file manager and copy the folder address.
  2. Add it below. Give the folder a name, paste its address, then choose Scan now. Your files stay where they are.
  3. Open the listener. On a phone, use the laptop’s Wi-Fi address while both devices are on the same network. This Host page stays on the laptop.

Library folders

Folders stay on this computer. Listeners see music, never these paths. All enabled folders contribute to the listener. To use only one, disable the others below. Adding a folder does not replace existing folders.

Add a music folder

On Windows, open the folder in File Explorer, press Alt+D then Ctrl+C, and paste that address here. Music stays in the folder; this does not upload it. Network folders are not supported here.

Folder actions never delete your files. Verification confirms which physical folder belongs to your library. Automatic updates may take up to a minute to reflect configuration changes.

Verify this folder?
